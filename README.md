Это веб-приложение для обмена информацией о просмотренных фильмах, разработанное с использованием Django и MySQL.

## Описание

Это приложение позволяет пользователям вести личный список фильмов, оперативно получать информацию о том, кто из сообщества какие фильмы недавно посмотрел или собирается посмотреть,
a также создавать собственные списки фильмов.

## Технологии

- Python 3.10
- Django 4.0
- MySQL 8.5
